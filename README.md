# ShortsForge - تطبيق تحرير الفيديو

## ما هو ShortsForge؟

ShortsForge هو تطبيق أندرويد مجاني يعمل **بدون اتصال بالإنترنت** لتحويل فيديوهات إنستغرام إلى مقاطع Shorts و Reels احترافية بجودة 9:16.

### المميزات الرئيسية

✅ **يعمل بدون إنترنت** - كل المعالجة تتم على جهازك  
✅ **قوالب جاهزة** - 10 قوالب قابلة للتعديل  
✅ **نصوص عربية** - دعم كامل للغة العربية مع خطوط Cairo و Tajawal  
✅ **ملصقات متحركة** - أسهم، دوائر، وغيرها  
✅ **تسجيل صوتي** - أضف تعليقاً صوتياً وأزل الصوت الأصلي  
✅ **جودة عالية** - تصدير 1080x1920 Full HD

## كيفية تحميل التطبيق

### الخطوة 1: اذهب إلى صفحة Releases
1. افتح GitHub في المتصفح
2. اذهب إلى صفحة Releases الخاصة بالمشروع
3. ابحث عن إصدار باسم **"Latest Build"** أو أي إصدار آخر

### الخطوة 2: حمل ملف APK
1. اضغط على اسم الإصدار
2. انزل إلى أسفل الصفحة
3. تحت قسم "Assets"، اضغط على `app-debug.apk`
4. سيتم تحميل الملف إلى جهازك

---

## كيفية التثبيت على أندرويد

### السماح بتثبيت التطبيقات من مصادر غير معروفة

#### لأندرويد 8 وما فوق:
1. عند محاولة تثبيت APK، سيظهر لك تحذير
2. اضغط على **"الإعدادات"** (Settings)
3. فعل خيار **"السماح من هذا المصدر"** (Allow from this source)
4. عد للخلف واضغط **"تثبيت"** (Install)

#### لأندرويد 7 وما دون:
1. اذهب إلى **الإعدادات** → **الأمان** (Settings → Security)
2. فعل خيار **"مصادر غير معروفة"** (Unknown Sources)
3. اضغط **"موافق"** (OK)
4. افتح ملف APK واضغط **"تثبيت"**

## كيفية الاستخدام (قريباً)

> ⚠️ هذه النسخة أولية. الميزات الكاملة ستكون متاحة في النسخ القادمة.

### النسخ القادمة ستدعم:
- استيراد فيديو من رابط إنستغرام
- استيراد فيديو من الجهاز
- اختيار القوالب وتطبيقها
- إضافة نصوص عربية/إنجليزية
- تسجيل صوتي وإزالة الصوت الأصلي
- تصدير الفيديو النهائي

## الإبلاغ عن مشكلة

إذا واجهت أي مشكلة:

1. **افتح صفحة Issues** على GitHub
2. اضغط على **"New Issue"**
3. اكتب وصف المشكلة بالعربية أو الإنجليزية
4. أضف:
   - نوع جهازك وإصدار أندرويد
   - خطوات reproducer المشكلة
   - صورة أو شاشة إذا أمكن
